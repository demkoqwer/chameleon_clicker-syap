# Современные языки программирования — лабораторные работы

Вариант 8: **«Эволюционный Кликер»** (Chameleon Clicker).
Выполнил: Демко А.В., группа 25-СТ.

Каждая лабораторная работа лежит в своей папке, со своим `README.md`, скриншотами и инструкцией по запуску.

| Папка | Лабораторная работа | Что реализовано |
|-------|---------------------|-----------------|
| [`lab1/`](lab1/) | **ЛР 1.** Алгоритмизация на Python (Pygame) | Игра-кликер: кнопка-мишень, попадание по формуле расстояния, уменьшение радиуса на 5%, сближение цветов, меню, HUD, экраны завершения |
| [`lab2/`](lab2/) | **ЛР 2.** Управление файлами и представление данных | Настройки в JSON с валидацией, лог событий, профили игроков в CSV, топ-3 на старте, ввод имени, множитель клика |
| [`lab3/`](lab3/) | **ЛР 3.** Telegram-бот (aiogram 3) | Бот-аналитик игры: рейтинг, статистика, ачивки, приём и проверка CSV, уведомления, JSON-сессии, FSM |

## Быстрый запуск

```
# ЛР 1 или ЛР 2 (игра)
cd lab2
pip install -r requirements.txt
python main.py

# ЛР 3 (бот): нужен токен от @BotFather в файле lab3/.env
cd lab3
pip install -r requirements.txt
python bot.py
```

Подробности — в README каждой папки.

## Как связаны работы

- `lab2` — развитие игры из `lab1` (те же классы, но параметры берутся из JSON, добавлены лог и таблица профилей).
- `lab3` — бот для игры. Он не повторяет игру, а анализирует файл `lab2/py_chameleon_clicker/clicker_profiles.csv`, который создаёт игра.
